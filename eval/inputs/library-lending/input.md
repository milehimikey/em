# Library Lending — PRD

A small public library wants to lend books to members and chase overdue loans.

- Members borrow a book from the catalog page. A loan records the member, the book and a due date.
- Members see their active loans on a "My Loans" page. A returned book disappears from that list.
- Librarians check a book back in at the returns desk.
- A loan that passes its due date without a return triggers an overdue notice to the member, sent automatically. Librarians can see which notices have gone out.

Out of scope: fines, reservations, e-books, member registration.
